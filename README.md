# Математические диагностики — независимая версия

Это самостоятельная копия уже реализованного сайта «Математика без стресса».
Она не использует ChatGPT Sites, авторизацию ChatGPT, Cloudflare Workers,
серверную базу данных или внешнее хранилище.

Сохранены страницы:

- `/` — диагностика перед 6 классом;
- `/7` — диагностика перед 7 классом;
- `/8` — диагностика перед 8 классом;
- `/9` — диагностика перед 9 классом;
- `/oge` — входная диагностика для подготовки к ОГЭ;
- `/after9` — диагностика после 9 класса.

Все ответы и прогресс по-прежнему хранятся только в браузере ученика.
Фотографии решений в диагностике после 9 класса хранятся в IndexedDB.

## Запуск на компьютере

Понадобится Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite.

## Готовая сборка

```bash
npm run build
```

Готовые статические файлы появятся в папке `dist`. Эту папку можно целиком
загрузить на любой статический хостинг.

Для проверки готовой сборки:

```bash
npm run preview
```

## GitHub Pages

1. Создайте новый репозиторий GitHub.
2. Загрузите в него все файлы проекта.
3. В настройках репозитория откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **GitHub Actions**.
5. Отправьте файлы в ветку `main`.

В проект уже добавлен сценарий `.github/workflows/deploy.yml`. Он автоматически
определит имя репозитория, соберёт сайт с правильным путём и опубликует его.

## Другой статический хостинг

Для собственного домена или размещения в корне сайта используйте обычную команду:

```bash
npm run build
```

Если сайт будет расположен не в корне домена, а в подпапке, задайте путь перед
сборкой:

```bash
VITE_BASE_PATH=/имя-папки/ npm run build
```

В Windows PowerShell:

```powershell
$env:VITE_BASE_PATH="/имя-папки/"
npm run build
```

## Что можно редактировать

- страницы и задания находятся в `app/`;
- общий дизайн находится в `app/globals.css`;
- переключение между страницами находится в `src/App.tsx`;
- адрес Telegram Леры задан константой `TELEGRAM_URL` в соответствующих страницах.

После изменений снова выполните `npm run build`.
